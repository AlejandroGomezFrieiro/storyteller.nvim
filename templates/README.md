# Storyteller project templates

Story structures shipped as JSON (`parts → chapters → scenes`), ported from
Kindling's bundled templates. Applied to a project with `:StoryTemplate`
(Phase 5).

Shipped here (Phase 5):
  - three-act
  - heroes-journey
  - save-the-cat
  - story-circle
  - seven-point   (Kindling ships this; the nixvim template omits it)

Format & application documented in `PLAN.md` / the plugin doc.
