# Storyteller Templates

These JSON files describe story structures as `parts`, `chapters`, and
`scenes`. Storyteller previews them before applying them with `:Story template`.

Included structures:

- Three Act
- Hero's Journey
- Save the Cat
- Story Circle
- Seven Point

Templates create missing chapter files and never overwrite existing ones. You
can point `templates_dir` at your own directory when you want to use a
different set of structures.
